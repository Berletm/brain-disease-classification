# MPCA-Attention

**Multi-branch MRI classification via orthogonal projections.**

Исследовательский проект по классификации МРТ головного мозга на шесть групп. Подход сочетает многомерный анализ главных компонент (Multilinear Principal Component Analysis, MPCA) и предобученные двумерные свёрточные сети. MPCA преобразует объёмные снимки в трёхканальные представления аксиальной, фронтальной и сагиттальной плоскостей. Независимые ветви CNN извлекают признаки, а многоголовое внимание объединяет информацию между плоскостями перед классификацией.

[Краткая препринт-версия статьи](report/preprint.pdf) и её [LaTeX-исходник](report/preprint.tex) описывают MPCA-Attention и программную реализацию. Подробные экспериментальные протоколы и численные результаты в публичную версию не включены.

## Архитектура

```text
Подготовленные трёхмерные МРТ-данные
        │
        ▼
MPCA-проекции: аксиальная / фронтальная / сагиттальная
        │
        ▼
Три RGB-представления → размер 224 × 224 → нормализация ImageNet
        │
        ▼
Независимые предобученные ветви CNN
        │
        ▼
Многоголовое внимание между плоскостями + остаточные соединения
        │
        ▼
Конкатенация → linear / ReLU / dropout / linear → логиты шести классов
```

Эксперимент по умолчанию в [src/clf.py](src/clf.py) использует ConvNeXt-Tiny, скрытый слой классификатора на 512 элементов, размерность внимания 128 и 32 головы внимания. Признаки каждой плоскости выступают запросом, а признаки всех трёх плоскостей — ключами и значениями. Ранние слои ветвей ConvNeXt заморожены; последний блок извлечения признаков остаётся обучаемым.

Также реализованы базовые сети ResNet, одноветвистая классификация, конкатенация и усреднение признаков, слияние с помощью двунаправленной LSTM. В [src/focal.py](src/focal.py) реализована взвешенная Focal Loss со сглаживанием меток. Оценка возвращает значение функции потерь, Accuracy, Macro F1, Macro Recall, Macro Precision и матрицу ошибок.

## Установка

Окружение разработки использует **Python 3.14.4**; версия записана в [.python-version](.python-version). Версии прямых зависимостей для выполнения кода и тестов зафиксированы в [requirements.txt](requirements.txt). Установите указанную версию Python и выполните команды из корня репозитория:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

Для работы на GPU нужна сборка PyTorch, совместимая с вашим окружением CUDA. Классификатор автоматически выбирает CUDA при её наличии, иначе использует CPU. При создании базовой сети запрашиваются стандартные предобученные веса torchvision; при первом запуске может потребоваться их загрузка.

## Данные и настройка

В полной рукописи описана выборка из 358 МРТ-исследований, объединённых из ADHD-200, ABIDE, OASIS, PPMI, IXI и набора ISBI для рассеянного склероза. 

| Метка | Группа | Подстрока имени файла | Число исследований по рукописи |
| --- | --- | --- | --- |
| 0 | Контрольная группа | `control` | 82 |
| 1 | Болезнь Паркинсона | `parkinson` | 40 |
| 2 | Болезнь Альцгеймера | `alzheimer` | 44 |
| 3 | СДВГ | `adhd` | 96 |
| 4 | Рассеянный склероз | `sclerosis` | 17 |
| 5 | Расстройство аутистического спектра | `autism` | 79 |

`AxisHolder` ожидает одинаковые имена файлов в трёх каталогах:

```text
dataset/
├── axial/
│   └── control_0.png
├── frontal/
│   └── control_0.png
└── sagital/
    └── control_0.png
```

Имена файлов в примере условные. Сохраните используемое в коде написание каталога `sagital`. `SliceHolder` читает отдельные изображения из плоского каталога, например `heuristic_dataset/`. Изображения преобразуются в RGB.

Укажите собственные пути к исходным МРТ в [src/utils.py](src/utils.py). Скрипты подготовки читают исходные каталоги через NiBabel: они должны содержать совместимые объёмные файлы, например NIfTI, без посторонних элементов.

### Подготовка проекций

После настройки путей к исходным данным и выполнения необходимой внешней предобработки:

```bash
cd src
python mpca.py
```

Скрипт приводит объёмы к общей форме, нормализует интенсивности по процентильным границам, центрирует набор данных и обучает линейную MPCA для каждой плоскости. PNG-проекции записываются в `dataset/`, матрицы проекций — в `models/mpca/`. Обрабатываются все настроенные исходные наборы данных; существующие изображения проекций и матрицы могут быть перезаписаны.

Для альтернативного эвристического отбора срезов выполните из корня репозитория:

```bash
mkdir -p heuristic_dataset
cd src
python heuristic.py
```

Скрипт ранжирует срезы по оценкам на основе ковариации и записывает трёхканальные изображения в `heuristic_dataset/`. Он также обрабатывает все настроенные исходные наборы данных и может перезаписать созданные изображения.

### Обучение и оценка

При наличии корректных изображений проекций выполните из корня репозитория:

```bash
mkdir -p models
cd src
python clf.py
```

Команда запускает настроенный эксперимент: до 100 эпох с ранней остановкой. По умолчанию используются стратифицированное разбиение 80/20 с `random_state=42`, размеры батчей 8/4 для обучения и оценки, взвешенная Focal Loss с gamma 3 и сглаживанием 0.188, AdamW и снижение скорости обучения при выходе функции потерь на плато. Скорость обучения основной группы параметров — `3e-4`, обучаемых групп базовых сетей — `1e-6`.

Каждый запуск создаёт нумерованный каталог `models/zN/` с файлами `training.log`, `best_multi.pth` и `multi.pth`. Выбранная лучшая модель оценивается, её матрица ошибок сохраняется в `report/utils/conf_mat.png`; скрипт также отображает график. Контрольные точки содержат сериализованные объекты моделей, а не только словари параметров.

## Тестирование

Выполните из корня репозитория:

```bash
python -m pytest -q tests
python -m compileall -q src tests
```

[Тесты датасетов](tests/test_data_augmentation.py) используют временные синтетические изображения для проверки меток, приоритета подстрок в именах, порядка перечисления файлов, преобразования в RGB, применения трансформаций, форм тензоров и поведения неизвестных имён. Частные МРТ-данные, предобученные веса и обучение моделей не требуются.

## Сборка препринта

Препринт использует тот же журнальный класс `kioj6`, что и полная рукопись. Установите дистрибутив TeX с XeLaTeX, а также пакеты и шрифты, требуемые [report/kioj6.cls](report/kioj6.cls), включая Fourier OpenType и Droid. Затем выполните из корня репозитория:

```bash
cd report
xelatex -interaction=nonstopmode -halt-on-error preprint.tex
xelatex -interaction=nonstopmode -halt-on-error preprint.tex
```

Команды создают `preprint.pdf` с основным текстом на русском и английской аннотацией в конце. Для сборки нужен `kioj6.cls`; инструменты обработки библиографии и иллюстрации полной статьи не требуются.
