# MPCA-Attention

**Multi-branch MRI classification via orthogonal projections.**

Исследовательский проект по классификации МРТ головного мозга на шесть групп. Подход сочетает многомерный анализ главных компонент (Multilinear Principal Component Analysis, MPCA) и предобученные двумерные свёрточные сети. MPCA преобразует объёмные снимки в трёхканальные представления аксиальной, фронтальной и сагиттальной плоскостей. Независимые ветви CNN извлекают признаки, а многоголовое внимание объединяет информацию между плоскостями перед классификацией.

[Краткая препринт-версия статьи](report/preprint.pdf) и её [LaTeX-исходник](report/preprint.tex) описывают MPCA-Attention и программную реализацию.

## Архитектура

```text
Подготовленные трёхмерные МРТ-данные
        │
        ▼
MPCA-проекции: аксиальная / фронтальная / сагиттальная
        │
        ▼
Три RGB-представления → размер 224 × 224 → нормализация ImageNet
        │
        ▼
Независимые предобученные ветви CNN
        │
        ▼
Многоголовое внимание между плоскостями + остаточные соединения
        │
        ▼
Конкатенация → linear / ReLU / dropout / linear → логиты шести классов
```

Эксперимент по умолчанию в [src/clf.py](src/clf.py) использует ConvNeXt-Tiny, скрытый слой классификатора на 512 элементов, размерность внимания 128 и 32 головы внимания. Признаки каждой плоскости выступают запросом, а признаки всех трёх плоскостей — ключами и значениями. Ранние слои ветвей ConvNeXt заморожены; последний блок извлечения признаков остаётся обучаемым.

Также реализованы базовые сети ResNet, одноветвистая классификация, конкатенация и усреднение признаков, слияние с помощью двунаправленной LSTM. В [src/focal.py](src/focal.py) реализована взвешенная Focal Loss со сглаживанием меток. Оценка возвращает значение функции потерь, Accuracy, Macro F1, Macro Recall, Macro Precision и матрицу ошибок.

## Установка

Окружение разработки использует **Python 3.14.4**; версия записана в [.python-version](.python-version). Версии прямых зависимостей для выполнения кода и тестов зафиксированы в [requirements.txt](requirements.txt). Установите указанную версию Python и выполните команды из корня репозитория:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip check
```

Для работы на GPU нужна сборка PyTorch, совместимая с вашим окружением CUDA. Классификатор автоматически выбирает CUDA при её наличии, иначе использует CPU. При создании базовой сети запрашиваются стандартные предобученные веса torchvision; при первом запуске может потребоваться их загрузка.
