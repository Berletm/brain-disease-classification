# MPCA-Attention

**Multi-branch MRI classification via orthogonal projections.**

Исследовательский проект по классификации МРТ головного мозга на шесть групп. Подход сочетает многомерный анализ главных компонент (Multilinear Principal Component Analysis, MPCA) и предобученные двумерные свёрточные сети. MPCA преобразует объёмные снимки в трёхканальные представления аксиальной, фронтальной и сагиттальной плоскостей. Независимые ветви CNN извлекают признаки, а многоголовое внимание объединяет информацию между плоскостями перед классификацией.

[Краткая препринт-версия статьи](report/preprint.pdf) и её [LaTeX-исходник](report/preprint.tex) описывают MPCA-Attention и программную реализацию.

## Архитектура

```text
Подготовленные трёхмерные МРТ-данные
        │
        ▼
MPCA-проекции: аксиальная / фронтальная / сагиттальная
        │
        ▼
Три RGB-представления → размер 224 × 224 → нормализация ImageNet
        │
        ▼
Независимые предобученные ветви CNN
        │
        ▼
Многоголовое внимание между плоскостями + остаточные соединения
        │
        ▼
Конкатенация → linear / ReLU / dropout / linear → логиты шести классов
```

Эксперимент запускается через [src/experiments/run.py](src/experiments/run.py), а архитектуры объявлены в [src/models/architectures.py](src/models/architectures.py). Конфигурация по умолчанию использует ConvNeXt-Tiny, скрытый слой классификатора на 512 элементов и PyTorch MHA размерности 576 с 24 головами. Признаки каждой плоскости выступают запросом, а признаки всех трёх плоскостей — ключами и значениями. Ранние слои ветвей ConvNeXt заморожены; последний блок извлечения признаков остаётся обучаемым.

Также реализованы базовые сети ResNet, одноветвистая классификация, конкатенация и усреднение признаков. В [src/models/losses.py](src/models/losses.py) реализована взвешенная Focal Loss со сглаживанием меток. Исправленная оценка сохраняет Accuracy, Macro F1, поклассовые метрики и матрицу ошибок.

## Установка

Проект использует **Python 3.14.4**, локальное окружение `.venv` и менеджер **uv**. Зависимости описаны в `pyproject.toml`, точные версии зафиксированы в `uv.lock`.

```bash
uv sync --locked
uv run pytest -q
uv run python -m src.experiments.run --cfg job
```

`uv run` использует окружение проекта независимо от активированного внешнего окружения. Запуски экспериментов и локальный MLflow описаны в [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md). `requirements.txt` сохранён как совместимый экспорт; зависимости изменяются через `uv add` / `uv remove`.

Для работы на GPU нужна сборка PyTorch, совместимая с вашим окружением CUDA. Устройство задаётся параметром Hydra `device=cpu` или `device=cuda`. При создании базовой сети запрашиваются стандартные предобученные веса torchvision; при первом запуске может потребоваться их загрузка.

## Данные

В исходной рукописи заявлены 358 исследований. Аудит выявил дубликат в группе Альцгеймера, повторные обследования четырёх пациентов с РС и перепутанные папки ADHD-200/NYU. После подтверждения диагнозов по CSV и BIDS TSV папки исправлены, обе группы NYU включены в конфиг. Текущие количества относятся к исследованиям, а не к независимым пациентам.

| Метка | Группа | Заявлено в статье | После проверки |
| --- | --- | --- | --- |
| 0 | Контрольная группа | 82 | 178 |
| 1 | Болезнь Паркинсона | 40 | 40 |
| 2 | Болезнь Альцгеймера | 44 | 43 |
| 3 | СДВГ | 96 | 39 |
| 4 | Рассеянный склероз | 17 | 17 (4 пациента) |
| 5 | Расстройство аутистического спектра | 79 | 79 |
| | Всего | 358 | 396 |

Состав задаётся в `configs/dataset/mri.yaml`, корень — через `MRI_DATASET_ROOT`. Метки нового runner берутся из локального реестра, а не из подстрок имён PNG. Все 425 активных NIfTI на носителе приведены к LAS; 29 файлов autism_old пока не включены из-за неподтверждённого соответствия исходным пациентам.

Для исправленной оценки используется 4 внешних × 3 внутренних фолда с разделением по пациентам и обучением MPCA внутри фолдов. Восстановлены подтверждённые ID для 152 обследований; для остальных 244 обследований соответствие пациентам ещё проверяется. Полная кросс-валидация ещё не запускалась; пробное train-only обучение выполнено на CUDA; старые метрики не являются оценками исправленной выборки. Подробности — [AUDIT.md](docs/AUDIT.md).
